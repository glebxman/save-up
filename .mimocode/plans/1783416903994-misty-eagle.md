# План: Очистка и унификация дизайн-системы Save Up

## Контекст

Проект использует Tailwind CSS v4 + CSS custom properties. При полной проверке найдены серьёзные несоответствия: мёртвый конфиг Tailwind, захардкоженные цвета вместо токенов, 6 вариантов трекинга для одного паттерна, 3 системы стилей одновременно, и многое другое. Цель — привести проект к единому стандарту.

---

## Этап 1: Удаление мёртвого конфига и неиспользуемых CSS-переменных

### 1.1 Удалить `tailwind.config.js`
Файл полностью игнорируется Tailwind v4 (Vite-плагин использует `@import "tailwindcss"` без `@config`). Все 9 расширений в `theme.extend` не используются ни в одном компоненте:
- `colors.ink`, `mist`, `sand`, `lagoon`, `amber`, `coral`
- `boxShadow.glow`
- `borderRadius.shell`
- `backgroundImage.grain`

**Файл:** `apps/client/tailwind.config.js` — удалить полностью.

### 1.2 Удалить мёртвые CSS custom properties из `index.css`
17 переменных определены, но никогда не используются через `var()`:

- `--segment` (строка 87)
- `--segment-foreground` (строка 88)

**Dark theme (строки 139-226):**

## Этап 3: Унификация типографики

### 3.1 Стандартизировать tracking для uppercase eyebrow/label
6 разных значений для одного паттерна. Стандарт: `tracking-[0.16em]` + `text-[10px]` (consensus между существующими `0.14em` и `0.18em`).

| Файл | Строка | Было | Стало |
|------|--------|------|-------|
| BalanceCard.tsx | 386 | `tracking-[0.2em]` | `tracking-[0.16em]` |
| SettingsSection.tsx | 25 | `tracking-[0.18em]` | `tracking-[0.16em]` |
| RecurringStrip.tsx | 38, 59 | `text-[11px] tracking-[0.18em]` | `text-[10px] tracking-[0.16em]` |

### 3.2 Унифицировать `text-[11px]` → `text-[0.6875rem]` или `text-xs`
16 использований `text-[11px]`. Варианты:
- Заменить на `text-xs` (12px) где разница не критична (подписи, описания)
- Заменить на `text-[0.6875rem]` (11px в rem) где 11px важен

**Рекомендация:** для подписей под значениями (`SavingsTile:54,68`, `DailyLimitTile:51`) оставить 11px но через rem. Для остальных — `text-xs`.

### 3.3 Исправить family override в SettingsSection
**Файл:** `apps/client/src/components/features/settings/SettingsSection.tsx`
- Строка 26: удалить `style={{ fontFamily: "sf_pro, 'SF Pro', -apple-system, sans-serif" }}`
- Глобальный `font-family` из `index.css:4` уже определяет Manrope

### 3.4 Унифицировать font-weight для currency badge
**Файл:** `apps/client/src/components/features/input/AmountInput.tsx`
- Строка 128: `font-bold` → `font-semibold` (consistency с Chip.tsx)

## Этап 4: Унификация spacing и compact-вариантов

### 4.1 Добавить size="xs" в Button
Вместо `!important` хаков в SavingsTile (строки 83, 91), добавить третий размер:

**Файл:** `apps/client/src/components/ui/Button.tsx`
```ts
type ButtonSize = "xs" | "sm" | "md";

// Добавить:
xs: "min-h-8 rounded-[12px] px-2.5 text-xs font-semibold",
```

После этого в SavingsTile.tsx заменить:
- `"!min-h-8 !rounded-[12px] !text-xs !font-semibold"` → `size="xs"`

### 4.2 Добавить size="compact" в CardContent
Вместо `!p-4` (7 использований), добавить проп:

**Файл:** `apps/client/src/components/ui/Card.tsx`
```ts
interface CardContentProps extends HTMLAttributes<HTMLDivElement> {
  compact?: boolean;
}
```
С `compact`: `"p-4"` вместо дефолтного `"p-5 sm:p-6"`.

После этого во всех файлах с `!p-4` заменить на `<CardContent compact>`.

### 4.3 Унифицировать grid gap
Стандартизировать `gap-2` (8px) для 2-колоночных сеток. Убрать `gap-3` из:
- `MonthReport.tsx:26`
